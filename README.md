# Worksite Safety

Static website for https://worksite-safety.ca hosted by GitHub Pages from the main branch, repository root.

- `index.html`: Prince Bhangu certification profile.
- `sign-in.html`: sign-in visual preview; account authentication is not connected.
- `sign-in-reference.png`: supplied design reference used for the logo and artwork.

Issue date: October 13, 2026. Expiry date: October 13, 2029.

Porkbun DNS: root ALIAS and www CNAME point to surinder-oss.github.io. The CNAME file configures the custom domain. Account controls are a visual preview and do not authenticate or store credentials.
